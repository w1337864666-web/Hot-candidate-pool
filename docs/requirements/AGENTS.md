# Product Requirements

本目录记录产品意图、用户需要、验收标准和产品边界。开始产品功能任务时先阅读这里，并用 `search` 或 `检索` 查找相关用户流程；不要把实现细节或技术决策原因当作需求来源。

## Requirement Index

- [`PRODUCT_REQUIREMENTS.md`](PRODUCT_REQUIREMENTS.md)：候选内容池的目标用户、核心流程、验收标准和明确不做事项。

## Maintenance Workflow

- 新的用户目标、验收条件或产品边界写入需求文档。
- 架构和实现方式写入 `docs/technical/`；稳定工程约束写入 `docs/specs/`。
- 交付演示材料仍放在 [`../DELIVERY.md`](../DELIVERY.md) 和 [`../DEMO_SCRIPT.md`](../DEMO_SCRIPT.md)。
